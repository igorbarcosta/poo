## Macroestrutura

### Unidade 1 — Objetos e Responsabilidades

**Parte 1 → CP1 → Parte 2 → CP2 → Parte 3 → Prova U1**

### Unidade 2 — Colaboração, Contratos e Polimorfismo

**Parte 1 → CP3 → Parte 2 → CP4 → Parte 3 → Prova U2**

### Unidade 3 — Evolução de Software Orientado a Objetos

**Parte 1 → CP5 → Parte 2 → CP6 → Parte 3 → Prova U3**

### Encerramento

Após o percurso regular, haverá a **Avaliação Substitutiva Cumulativa**.

A Parte 3 de cada unidade é um período efetivo de consolidação, integração, leitura, análise e transferência para novos problemas. Por isso, os checkpoints não serão posicionados imediatamente antes das provas.

Novas datas serão acrescentadas a esta página quando forem confirmadas. Avisos e orientações operacionais serão divulgados no Google Classroom. O cronograma não fixa antecipadamente um número de encontros nem uma distribuição semanal rígida.
