# Referências e recursos

Esta página distingue a bibliografia institucional do curso das recomendações didáticas atuais da disciplina. Use as indicações para escolher materiais de acompanhamento, consulta ou aprofundamento conforme sua necessidade.

## Bibliografia básica — PPC vigente

Estas referências correspondem à bibliografia básica registrada no PPC vigente do curso.

1. DEITEL, H.; DEITEL, P. **Java: como programar**. 8. ed. Pearson Brasil, 2010.
2. SANTOS, R. **Introdução à programação orientada a objetos usando Java**. Rio de Janeiro: Elsevier, 2003. ISBN 9788535212068.
3. SIERRA, K. **Use a cabeça!: Java**. 2. ed. [S.l.]: Alta Books, 2009.

!!! info "Caráter institucional"

    As edições acima foram preservadas conforme o PPC vigente. Elas não representam necessariamente as edições mais recentes disponíveis.

## Referências atualizadas recomendadas

As referências abaixo são recomendações didáticas da disciplina e não substituem formalmente a bibliografia registrada no PPC vigente.

### Use a Cabeça Java — 3ª edição

**SIERRA, Kathy; BATES, Bert; GEE, Trisha. _Use a Cabeça Java_. Tradução da 3ª edição. Alta Books. ISBN 9788550819884.**

**Indicado para:** acompanhamento e aprendizagem inicial.

É a atualização direta de uma obra presente no PPC. Sua abordagem visual e didática favorece estudantes que estão aprendendo Java e consolidando orientação a objetos, podendo funcionar como uma das principais leituras complementares do curso.

[Consultar no site da Alta Books](https://altabooks.com.br/produto/seja-um-analista-de-dados/)

### Objects First with Java — 7ª edição

**BARNES, David J.; KÖLLING, Michael. _Objects First with Java: A Practical Introduction Using BlueJ_. 7th ed. Pearson, 2025. ISBN 9780138087173.**

**Indicado para:** aprendizagem conceitual de orientação a objetos e desenvolvimento de software.

A organização a partir de objetos e conceitos de desenvolvimento aproxima o livro da abordagem da disciplina, centrada em responsabilidades e evolução de software. O livro utiliza BlueJ como ambiente didático, mas a disciplina não adota BlueJ como ambiente obrigatório.

[Consultar no site da Pearson](https://www.pearson.com/en-us/subject-catalog/p/objects-first-with-java-a-practical-introduction-using-bluej/P200000010666/9780138087173)

### Java How to Program: An Objects-Natural Approach — 12ª edição

**DEITEL, Paul; DEITEL, Harvey M. _Java How to Program: An Objects-Natural Approach_. 12th ed. Pearson, 2025. ISBN 9780138362171.**

**Indicado para:** consulta ampla e exemplos de implementação.

É uma atualização moderna da família de livros Deitel presente no PPC. A cobertura extensa e os muitos exemplos completos tornam a obra especialmente útil para consultar tópicos específicos de Java; sua leitura integral não é requisito da disciplina.

[Consultar no site da Pearson](https://www.pearson.com/en-us/subject-catalog/p/java-how-to-program-an-objects-natural-approach/P200000003250/9780138362171)

### Core Java, Volume I: Fundamentals — 14ª edição

**HORSTMANN, Cay S. _Core Java, Volume I: Fundamentals_. 14th ed. Oracle Press, 2026. ISBN 9780135558577.**

**Indicado para:** aprofundamento e consulta técnica.

É uma referência mais detalhada sobre a linguagem e suas APIs, adequada para quem deseja aprofundar conhecimentos de Java. Não é a leitura introdutória prioritária da disciplina.

[Consultar no site da editora](https://www.informit.com/store/core-java-volume-i-fundamentals-9780135558577)

## Recursos online

### Dev.java — Learn Java

O [Dev.java — Learn Java](https://dev.java/learn/) é a principal referência online recomendada para Java nesta disciplina. Mantido no ecossistema oficial da linguagem, reúne materiais atualizados sobre fundamentos, classes, objetos e outros recursos, além de orientações para ambientes como IntelliJ IDEA, VS Code e Eclipse.

### Oracle University — treinamento gratuito de Java

A Oracle University oferece o percurso gratuito [Java Explorer](https://learn.oracle.com/ols/learning-path/java-explorer/88323/79726), com módulos sobre fundamentos de Java, incluindo variáveis, classes, objetos, estruturas de decisão, loops e arrays. Pode ser usado como material complementar; não constitui atividade obrigatória da disciplina.

### Java Programming — University of Helsinki

O [Java Programming MOOC](https://java-programming.mooc.fi/) da University of Helsinki possui explicações conceituais e muitos exercícios de programação.

!!! warning "Material legado"

    A própria universidade classifica esse curso como legado: o conteúdo não recebe mais atualização ou manutenção. Ele ainda pode ser útil pelos exercícios, mas não deve ser usado como referência para recursos recentes do Java.
