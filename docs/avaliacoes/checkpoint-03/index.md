# Checkpoint 03 — Contratos, colaboração e testes

O Checkpoint 03 trabalhou interfaces e tipos de referência, distribuição de
responsabilidades, conservação de colaboradores, acompanhamento do estado e
testes capazes de distinguir implementações corretas de alterações defeituosas.
