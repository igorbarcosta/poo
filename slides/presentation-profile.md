# POO presentation profile

- Identity: `poo-marp-v1`
- Owner: the POO consumer repository.
- Format: Marp Markdown using `slides/theme/poo.css`.
- Language: Portuguese for pedagogical content; Java syntax remains unchanged.
- Delivery: a 90-minute presencial lesson.
- Density: one central idea per frame, with progressive code and purposeful
  activity pauses.
- Local conventions: `chapter`, `concept-key`, `java-focus`, `activity`,
  `tip`, `trap`, and `synthesis`, plus the existing POO components and notes.

This profile configures the consumer projection. It does not change Docemas
semantic contracts, perform rendering, or authorize publication.
